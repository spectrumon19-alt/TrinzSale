================================================================================
                          DEPLOYMENT INSTRUCTIONS
================================================================================

1. PUSH CODE TO GITHUB
   $ git add -A
   $ git commit -m "Deploy TrintzERP to Render with P&L reports"
   $ git push origin main

2. CREATE RENDER WEB SERVICE
   - Go to https://render.com
   - Click "New +" → "Web Service"
   - Select your GitHub repository
   - Name: trintzerp
   - Environment: Python 3
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn --bind 0.0.0.0:$PORT --workers 2 --timeout 120 --preload wsgi:application
   - Plan: Starter ($7/month)

3. ADD ENVIRONMENT VARIABLES
   In Render Dashboard → Service → Environment, add all variables from DEPLOY_CHECKLIST.md
   
   CRITICAL VARIABLES:
   - SECRET_KEY (32+ character hex string)
   - DB_HOST, DB_NAME, DB_USER, DB_PASSWORD (PostgreSQL)
   - BREVO_API_KEY, BREVO_SENDER_EMAIL, BREVO_SMTP_USER, BREVO_SMTP_PASSWORD

4. DEPLOY
   Click "Deploy" button and monitor logs
   Pre-deployment checks will run automatically

5. VERIFY
   - Access https://your-service.onrender.com
   - Login with credentials
   - Test P&L Report → Generate Report → Export to Excel
   - Verify daily breakdown sheet exists and has data

================================================================================
                              SUPPORT
================================================================================

If deployment fails:
1. Check Render logs (Dashboard → Logs tab)
2. Run `python predeploy.py` locally to diagnose
3. Verify all environment variables are set correctly
4. Ensure database credentials are correct
5. Check if dependencies are missing from requirements.txt

Common issues:
- SECRET_KEY not set → Add to environment variables
- Database connection fails → Verify DB_* variables
- Pre-deploy check fails → Check logs for specific error
- App crashes → Review app logs, check imports
- Email not working → Verify Brevo credentials
