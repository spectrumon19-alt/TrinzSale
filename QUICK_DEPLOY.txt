   → Start Command: gunicorn --bind 0.0.0.0:$PORT --workers 2 --timeout 120 --preload wsgi:application

COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════════════════════════

ERROR: "SECRET_KEY not set"
FIX: Add SECRET_KEY to Render Environment Variables

ERROR: "Database connection failed"
FIX: Verify all DB_* environment variables are set correctly

ERROR: "Pre-deployment check failed"
FIX: Check Render logs (Dashboard → Logs tab) for specific error

ERROR: "502 Bad Gateway"
FIX: Check app logs, increase timeout or workers in startCommand
