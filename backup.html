How to set up Google Drive backup:
1. Go to console.cloud.google.com → Create a new project
2. Enable Google Drive API
3. Create a Service Account → Create JSON key → download it
4. In Google Drive, create a folder → Share it with the service account email
5. Copy the folder ID from the Drive URL: drive.google.com/drive/folders/[this part]
6. Upload the JSON key file above and paste the folder ID
