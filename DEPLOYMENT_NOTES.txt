TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Screen Still Flashing?
- Clear browser cache (Ctrl+Shift+Delete)
- Verify license_activation.html has critical CSS in <head>
- Check network latency (API calls taking too long?)

Purchase Invoice Edit Not Working?
- Verify /api/purchase/{id} endpoint is responding
- Check authentication token in localStorage
- Verify all fields are actually inputs (no readonly)

Excel Import Errors?
- Verify column headers match exactly
- Check required columns: Supplier Name, Supplier GST Number, etc.
- Ensure Product Name matches products in database

Data Download Not Working?
- Verify /api/data/export/* endpoints exist
- Check authentication token
- Ensure user has admin privileges
